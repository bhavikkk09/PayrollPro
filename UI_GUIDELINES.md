# UI_GUIDELINES.md — Design System & Front-End Style Guide

## Design Principles
1. **Glassmorphism & Vibrancy**: Dark mode backdrop with translucent cards, crisp borders (`border-slate-800`), smooth gradients, and interactive hover states.
2. **Typography**: Clean sans-serif hierarchy using Inter/Roboto with readable font scaling and accessible contrast.
3. **Data Density**: High-density tables with responsive horizontal scrolling, fixed header position, and virtualized list options.

## Design Tokens & Palette
* **Background Primary**: `#090d16` (Deep Space Navy)
* **Card Surface**: `#111827` / `#1e293b` with `backdrop-blur-md`
* **Accent Brand Color**: Indigo / Cyan (`#6366f1` / `#06b6d4`)
* **Success Indicator**: Emerald (`#10b981`)
* **Warning / Flagged**: Amber (`#f59e0b`)
* **Error / Alert**: Rose (`#f43f5e`)

## Standard UI Components
* **Cards & Containers**: Rounded corners (`rounded-xl`), subtle shadows (`shadow-lg`), and crisp border outlines (`border border-slate-800/80`).
* **Buttons**: Primary gradient buttons (`bg-gradient-to-r from-indigo-600 to-indigo-700 hover:from-indigo-500 hover:to-indigo-600`), secondary dark outlined buttons.
* **Badges**: Status pills (`px-2.5 py-1 text-xs rounded-full font-medium`).
